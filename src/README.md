# 🚀 Galaxy Remastered

A futuristic reimagining of classic retro arcade
space-shooter gameplay.

Galaxy Remastered combines classic arcade simplicity
with modern visuals, effects, progression and gameplay.

## Status

🚧 Early Development — Prototype

## Technology

- TypeScript
- Vite
- HTML5 Canvas
- CSS
- Node.js

## Current Features

- Shooting, enemy formations and dive attacks
- Enemy fire, score, shield and game over
- Stage and wave progression
- Full-screen space environment
- Animated starfield
- Futuristic player spaceship
- WASD controls
- Arrow-key controls
- Neon HUD

## Controls

| SPACE | Fire |
| R | Restart (after game over) |
| Key | Action |
|---|---|
| W / ↑ | Move Up |
| S / ↓ | Move Down |
| A / ← | Move Left |
| D / → | Move Right |
| SPACE | Fire (planned) |
