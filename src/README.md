# 🚀 Galaxy Remastered

A futuristic reimagining of classic retro arcade
space-shooter gameplay.

Galaxy Remastered combines classic arcade simplicity
with modern visuals, effects, progression and gameplay.

## Status

🚧 Early Development — Phase 3 (Arcade Gameplay)

## Technology

- TypeScript
- Vite
- HTML5 Canvas
- CSS
- Node.js

## Current Features

- Full-screen space environment with animated starfield
- Futuristic player spaceship, neon HUD
- Shooting with cooldown
- Enemy waves, stages and difficulty scaling
- Enemy fire, score, shield and game over
- Power-ups: shield repair and timed double shot
- Persistent high score

## Controls

| Key | Action |
|---|---|
| W / ↑ | Move Up |
| S / ↓ | Move Down |
| A / ← | Move Left |
| D / → | Move Right |
| SPACE | Fire |
| R | Restart (after game over) |

## Development

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Production build:

```bash
npm run build
```
